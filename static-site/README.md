# نسخة سهم كابيتال الثابتة

هذه نسخة واجهة أمامية ثابتة من موقع شركة سهم كابيتال المالية، مخصصة للتجربة والتعديل عبر Visual Studio Code وLive Server. لا تحتاج إلى Node أو قاعدة بيانات.

## التشغيل

افتح مجلد `static-site` في Visual Studio Code، ثم ثبّت إضافة Live Server إن لم تكن موجودة. افتح `index.html` واضغط بزر الفأرة الأيمن ثم اختر **Open with Live Server**.

يمكن أيضاً فتح `index.html` مباشرة في المتصفح، لكن Live Server أفضل أثناء التطوير لأنه يعيد تحميل الصفحة بعد التعديلات.

## الملفات

- `index.html`: الهيكل العام والرأس والتذييل.
- `styles.css`: الهوية البصرية والتجاوب وتصميم المكونات.
- `app.js`: التنقل بين الصفحات والبيانات التجريبية والنماذج الأمامية.

## تنبيه التطوير

هذه النسخة لا تحفظ طلبات الاشتراك، ولا تحتوي على تسجيل دخول أو قاعدة بيانات أو لوحة إدارة حقيقية. النماذج تعرض رسائل تجريبية فقط. عند إنشاء الخادم لاحقاً، يمكن استبدال البيانات المحلية في `app.js` بطلبات API، وربط نموذج الاشتراك والمصادقة ولوحة الإدارة بقاعدة البيانات.

بيانات الأسواق والروابط الحالية تجريبية ويجب استبدالها قبل التسليم التجاري. غيّر المتغيرين `telegram` و`whatsapp` في أعلى ملف `app.js` إلى بيانات الشركة الرسمية.
